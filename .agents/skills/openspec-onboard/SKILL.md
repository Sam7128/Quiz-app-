# OpenSpec: Onboard

Teach the user the OpenSpec workflow through a real task.

## Phases

1. **Welcome**: Explain the workflow goals.
2. **Task Selection**: Scan codebase for TODOs or small fixes.
3. **Explore**: Brief demonstration of exploration stance.
4. **Creation**: Create the change container.
5. **Artifacts**: Draft Proposal, Specs, Design, and Tasks.
6. **Implementation**: Narrated task execution.
7. **Archive**: Finalize and preserve history.

## Guardrails
- Use the EXPLAIN -> DO -> SHOW -> PAUSE pattern.
- Keep narration focused on teaching the "Why" behind each step.
- Ensure the task remains small (~15-20 mins).
