## 2. Benchmark Scenarios & Execution Protocol

### Scenario A: Storage 批次清理與跨存儲銷毀基準
> 驗證 `clearUserDataOnSignOut` 是否能高效遍歷清理 `localStorage` 與 `sessionStorage` 中的敏感資料，同時精確保留白名單（主題、音效開關）。

| 參數 | 數值 / 條件 |
| :--- | :--- |
| **測試資料量** | 模擬 500 個 `mindspark_bank_*` + `mindspark_ai_config` (sessionStorage) |
| **白名單驗證** | `mindspark_theme`, `mindspark_bgm_enabled`, `mindspark_sfx_enabled` |
| **預期耗時** | < 10ms |
| **驗收標準** | 1. 所有非白名單 `mindspark_*` 鍵值 100% 銷毀<br>2. `sessionStorage` 內 AI Key 100% 銷毀<br>3. 白名單項目完整保留 |

---

### Scenario B: 間隔重複 `spaced_due` 排序防洗牌與跨題庫取題
> 驗證當點擊「複習到期題目」時，演算法嚴格按 `nextReviewDate` 遞增排序，且**絕不被後續 `shuffleArray` 打亂**，並能跨題庫獲取所有到期題目。

| 參數 | 數值 / 條件 |
| :--- | :--- |
| **測試資料量** | 1,000 題到期記錄（分散於 5 個不同題庫） |
| **輸入條件** | UI 僅選中題庫 1，但題庫 2~5 亦含有到期題目 |
| **預期耗時** | 從呼叫 `startQuiz(count, 'spaced_due')` 到完成題目陣列構建 < 15ms |
| **驗收標準** | 1. 出題題目按 `nextReviewDate` 遞增 100% 嚴格單調不減<br>2. 跨題庫到期題目全數載入，無孤兒遺漏<br>3. 絕不觸發隨機洗牌 |

| :--- | :--- |
| **測試 Viewport** | 1366×768、1280×720、1920×1080、800×600 |
| **測試動作** | 快速切換視窗高度與作答選項高亮 |
| **預期 FPS** | 穩態 ≥ 58 FPS |

### Scenario D: 快捷鍵高頻連擊與修飾鍵 / IME 攔截守衛
> 驗證在使用者高頻點擊鍵盤、使用中文輸入法（IME 組字）、或觸發瀏覽器原生快捷鍵（如 `Ctrl+1` 切換標籤頁）時的防禦表現。

| 參數 | 數值 / 條件 |
| :--- | :--- |
| **事件發送頻率** | 模擬 50 次按鍵 / 秒（涵蓋 `1~4`, `Enter`, `Space`） |
| **干擾組合** | `Ctrl+1~4`, `Alt+Enter`, `Meta+1`, `keyCode: 229` (IME), `isComposing: true` |
| **預期延遲** | 鍵盤事件分發到 handler 執行 < 8ms |
| **驗收標準** | 1. 所有帶有修飾鍵（Ctrl/Alt/Meta）與 IME 組字事件 100% 被守衛放行（不觸發答題也不攔截原生事件）<br>2. 純數字鍵 `1~4` 正確觸發選項選取<br>3. 無任何記憶體累積或 Event Listener 洩漏 |

| 故障情境 | 注入方式 | 預期防禦行為 | 驗收標準 |
| :--- | :--- | :--- | :--- |
| **離線登出異常** | Mock `supabase.auth.signOut` 拋出 NetworkError | `try...finally` 機制確保本機清理照常執行 | 本地敏感資料 100% 清除，頁面導回登入 |

## 3. Automated Vitest Benchmark Code Skeletons

以下為可直接納入 `src/__tests__/` 執行的單元與基準測試驗證骨架：

```typescript
import { describe, it, expect, vi, beforeEach } from 'vitest';
import { getLocalDateString } from '@/utils/dateUtils';
import { clearUserDataOnSignOut, STORAGE_KEYS } from '@/services/storage';

describe('Benchmark: fix-p0-core-experience-and-security', () => {
  beforeEach(() => {
    localStorage.clear();
    sessionStorage.clear();
  });

  it('[Scenario A] Storage cleanup latency and whitelist preservation', () => {
    // 注入 500 筆測試資料
    for (let i = 0; i < 500; i++) {
      localStorage.setItem(`mindspark_bank_${i}`, JSON.stringify({ id: i }));
    }
    localStorage.setItem(STORAGE_KEYS.THEME, 'dark');
    sessionStorage.setItem('mindspark_ai_config', JSON.stringify({ apiKey: 'secret' }));

    const start = performance.now();
    clearUserDataOnSignOut();
    const duration = performance.now() - start;

    expect(duration).toBeLessThan(15); // < 15ms
    expect(localStorage.getItem(STORAGE_KEYS.THEME)).toBe('dark');
    expect(localStorage.getItem('mindspark_bank_0')).toBeNull();
    expect(sessionStorage.getItem('mindspark_ai_config')).toBeNull();
  });

  it('[Scenario B] Spaced Due Ordering Preservation (Anti-Shuffle)', () => {
    const items = [
      { id: 'q1', nextReviewDate: 1000 },
      { id: 'q2', nextReviewDate: 2000 },
      { id: 'q3', nextReviewDate: 3000 },
    ];
    // 驗證排序函式不變性
    const sorted = [...items].sort((a, b) => a.nextReviewDate - b.nextReviewDate);
    expect(sorted.map(i => i.id)).toEqual(['q1', 'q2', 'q3']);
  });

  it('[Scenario E] getLocalDateString handles Invalid Date gracefully', () => {
    const invalidDate = new Date(NaN);
    const result = getLocalDateString(invalidDate);
    expect(result).toMatch(/^\d{4}-\d{2}-\d{2}$/);
  });
});
```

## 4. Acceptance Criteria Matrix (總結驗收表)

| 測試場景 | 通過標準 (Pass Criteria) | 失敗判定 (Fail Criteria) |
| :--- | :--- | :--- |
| **A: 儲存清理** | 500 keys 清理時間 < 10ms，`sessionStorage` 敏感資料銷毀，白名單保留 | 清理耗時 > 30ms，或殘留敏感 Key |
| **B: 到期題排序** | 出題順序嚴格符合 `nextReviewDate` 遞增，跨題庫完整納入 | 順序被 `shuffleArray` 打亂，或漏載跨題庫到期題 |
| **C: 戰鬥舞台佈局** | 1366×768 下舞台高度 ≤ 28vh，4 個選項首屏清晰可見無需滾動 | 選項被擠出可視區域，或發生版面劇烈位移 (CLS > 0.1) |
| **D: 快捷鍵守衛** | 修飾鍵（Ctrl/Alt/Meta）與 IME 組字 100% 豁免，事件延遲 < 8ms | 誤觸發快捷鍵，或攔截了瀏覽器原生標籤頁切換 |
| **E: 故障注入韌性** | 離線斷網登出 100% 執行本機銷毀，無效 Date 產出合法字串 | 拋出未捕獲異常、本機敏感資料殘留或頁面崩潰 |
