## 2. Benchmark Scenarios

### Scenario A: Cold Start

| **Acceptance Criteria** | CSP does not block critical paths; AudioContext initializes instantly. |

### Scenario C: Peak Load (Concurrency Spike)

> Maximum expected operational load (e.g., user rapidly refreshing tabs or offline data flush).

| Parameter | Value |
|-----------|-------|
| **Concurrent Tabs** | 10 |
| **Sync Rate** | 10 simultaneous sync requests |
| **Spike Duration** | 1 minute |
| **Expected Behavior** | Web Locks queues requests gracefully. No fallback lock corruption. |
| **Max Acceptable Latency (p95)** | Lock acquired within 100ms (queued) |

### Scenario D: Sustained Stress (Soak Test)

> Extended duration at elevated load — detects memory leaks, especially for AudioContexts.

| Parameter | Value |
|-----------|-------|
| **Load Level** | Continuous Audio Notifications (FocusTimer) |
| **Duration** | 1 hour |
| **Memory Growth Tolerance** | < 1MB growth per hour |
| **AudioContext Leaks** | Active hardware contexts must stay at 0 between notifications. |
| **Success Criteria** | No OOM, no hardware audio channels exhausted (Max 6 on some OS). |

### Scenario E: Chaos / Fault Injection

> Behavior under failure conditions — validates resilience.

| Fault Type | Injection Method | Duration | Expected Behavior | Recovery Time Target |
|------------|-----------------|----------|--------------------|--------------------|
| Supabase Timeout | Mock fetch to hang >10s | 2 min | Web Lock stays held; Fallback lock expires but should not corrupt if guarded. | < 5s after timeout |
| Web Locks Disabled | Mock `navigator.locks` = undefined | Permanent | Gracefully degrades to timestamp fallback lock | Immediate |
| CSP Violation | Attempt fetch to unlisted proxy | 1 min | Blocked securely without crashing app | Immediate |

## 5. Memory Leak Detection Protocol

> **Purpose**: Detect gradual memory growth that indicates leaks, particularly with AudioContexts and Event Listeners.

### Test Procedure
1. Run Scenario D (FocusTimer repeated ringing).
2. Sample memory metrics using Chrome DevTools Heap Snapshot.
3. Validate `AudioContext` instances are GC'd.

### Leak Detection Criteria

| Metric | Pass | Marginal | Fail |
|--------|------|----------|------|
| Total Growth (1hr) | < 1 MB | 1–5 MB | > 5 MB |
| Active AudioContexts | 0 (when idle) | 1 | > 1 (Hardware limit hit soon) |
| Event Listeners (`keydown`) | 1 | 2 | > 2 |
