## ADDED Requirements

### Requirement: 圓形選單渲染
系統必須能夠在滑鼠當前位置彈出一個基於 PyQt6 的半透明圓形選單。選單應包含多個扇形區塊，每個區塊顯示一個標籤。

#### Scenario: 成功顯示選單
- **WHEN** 觸發全域快捷鍵時
- **THEN** 系統在滑鼠指針中心顯示圓盤選單，背景為半透明模糊效果。
- **AND** 視窗 flags 包含 `WindowStaysOnTopHint`, `FramelessWindowHint`, `Tool`

### Requirement: 動態交互選取
選單必須根據滑鼠與圓心的角度自動高亮對應的扇形區塊。

#### Scenario: 選項高亮
- **WHEN** 用戶在選單開啟狀態下移動滑鼠
- **THEN** 距離圓心一定半徑外的最近扇形區塊應變更顏色以示選中。

#### Scenario: 圓心死區
- **WHEN** 用戶的滑鼠在圓心半徑 30px 以內
- **THEN** 不高亮任何選項（視為「未選擇」狀態）

### Requirement: 多級選單導航
當選中的項目包含子分類時，系統必須能夠切換圓盤內容以顯示子分類選項。

#### Scenario: 進入子菜單
- **WHEN** 用戶在具有子分類的選項上放開按鍵或點擊
- **THEN** 圓盤內容瞬間更新為子分類的選項。

#### Scenario: 返回上層菜單
- **WHEN** 用戶按下 Esc 鍵或滑鼠右鍵
- **THEN** 圓盤內容恢復為上一層分類的選項。
- **AND** 如果已在最頂層，則關閉選單。

### Requirement: 取消操作
用戶必須能夠在不選擇任何項目的情況下關閉選單。

#### Scenario: 取消選單
- **WHEN** 用戶按下 Esc 鍵，或滑鼠在圓心死區內放開按鍵
- **THEN** 選單關閉，不執行任何注入操作。
